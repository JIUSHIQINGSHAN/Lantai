## 已知缺口与下一步（诚实测量）

- `API 密钥` 用例在 FTS 兜底路径下新值（环境变量注入）可召回，但旧值（config.py）因
  BM25 空格 token 计数/长度归一化被抬分而排在前——检索层目前**没有 supersedes 边感知排序**。
- `superseded_order_accuracy=0.5`：一半取代场景新值未置顶；`superseded_residual_rate=1.0`：
  被取代旧值全部仍出现在 top-k。两者是同一根因的两面。
- 方向（一年内档）：在 hybrid 打分后加入 supersedes 边降权/置顶（relation='supersedes'
  的旧值 penalize），并在评测集回归；修复遵循「宁 miss 不脏写」，不自动删旧值。
- 向量路径启用后该项预计显著改善（embedding 相似度可区分新旧值）；本报告为 FTS 兜底
  下界，是自证体系最严格基准。
