# 拾遗自适应补救诊断

基线为 `ad5df575`，工作分支为 `feat/shiyi-adaptive-remedy`。验证使用独立开发解释器、真实内存 SQLite 和公开的补救接口；没有启动生产服务或读取宿主记忆库。

## 确定性复现

`tests/test_shiyi_adaptive.py` 第一轮发现空查询经流水线再次输出前次候选，1 失败、4 通过；清空每次调用的候选并处理无效请求后，5 项通过。

第二轮用 `orionvectorizer` 查询 `orionvectorization deployment`，普通和全角查询均返回空，2 失败、6 通过。原因是仅整词 LIKE 预筛，后面的字符匹配接触不到变体；连续三元组预筛及实际重合判定后，与原有引擎和预算用例合计 27 项通过。

第三轮新增分阶与安全行为，9 失败、8 通过。证据分别为跨域高分挤掉同域结果、低衰减记忆没有回拨标记、分轨及缺失租户身份未受限、尚未生效和过期记忆进入当前召回、退役行回灌，以及显式零置信度被 `or 0.8` 改成默认值。

复核 ADR-0058 的共享约定时又增加同租户共享对照：不同租户、无租户但不同属主两例均错误放行，2 失败、1 通过。根因是共享分支在租户检查前直接返回，修复为先检查租户，再放行同租户共享，其他情况仍校验属主。

## 修复边界

修复限制在拾遗引擎：按同域、跨域、衰减回拨逐阶补缺；连续字符证据替代无序字符集合；授权及当前有效期先行过滤。回拨只更改候选的临时排序分，真实数据库衰减分不动，候选带回拨前后值以供复核。

扫描改为有限词项与三元组预筛、流式读取及跨阶共享预算，最多处理 512 个不同候选，截断保留部分结果。原有默认关闭、历史视图跳过、匿名服务入口收敛、内部无身份直调、逐字原文及更正过滤均由既有回归保护。

新增行为见 `tests/test_shiyi_adaptive.py`。原有接口与安全契约见 `tests/test_shiyi_remedy_contract.py`、`tests/test_opt_shiyi_entry_acl_smoke.py`、`tests/test_shiyi_supersede_filter.py` 以及引擎、流水线、API 冒烟测试。实际最终计数由任务报告记录，不把单模块通过等同于可发布。
