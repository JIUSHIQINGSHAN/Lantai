# ADR-0038: 悬镜——全功能可视化记忆管理控制台（Lantai Studio）

**日期**: 2026-08-31
**状态**: Accepted
**决策者**: 大哥
**来源**: 解决长期纯依靠 MCP 机机接口运维低效、缺乏全局认知透视的痛点。

---

## 背景

兰台系统已具备 55 个 MCP 工具与四路混合检索、沉潜折叠、探颐消歧等高级机制。然而：
1. 人类管理者审核待审候选、冲突账本、演化提案时，缺乏直观、低心智负担的可视化界面；
2. 缺乏在线编辑人格基座（器识 L/G/E）与工作区札记（Scratchpad）的所见即所得界面；
3. 缺乏检索演练场，无法直观观察向量分、BM25 分、FTS5 字串匹配与时效衰减的具体计算过程。

---

## 决策

构建**「悬镜」（Xuanjing · Lantai Studio）**可视化管理中台：

### 核心设计

1. **统一工作台架构（SPA）**：
   - 托管于 `/ui` 路由，零外部打包依赖，原生 ES Module；
   - 支持「吉金」（青铜深色）与「漏窗」（园林浅色）双典籍主题自适应；
2. **五大核心功能区**：
   - **案牍（Triage Hub）**：卡片式待审流，支持一键批准/拒绝候选与提案；
   - **器识与札记工作室（Persona & Scratchpad Studio）**：在线读取、配置与保存人格基座与即时便签；
   - **沉潜夜梦沉淀（Consolidation Console）**：一键触发夜梦沉淀、查看修剪统计与审计报告；
   - **检索与探针演练场（Playground）**：实时输入 Query，直观拆解四路召回得分与触发的探针；
   - **星图与全景档案（Map & Vault）**：拓扑关系连线与全库结构化记忆浏览。

---

## 影响

- 前端：升级 `lantai/api/ui/index.html`、`app.js`、`styles.css`
- 后端：`routes_ui.py` 提供静态资源服务与 API 聚合
- 测试：`tests/test_studio_ui.py`
