# ADR-0025: 案牍控制台采用无构建 ES Modules 与渐进迁移

**日期**: 2026-08-16
**状态**: Accepted
**决策者**: 大哥
**来源**: 兰台控制台工作台设计 grilling

## 背景

现有 `/ui` 是五个由 `routes_ui.py` 内联托管的独立页面目录。它部署简单，但页面之间没有
共享外壳、统一状态或可扩展的交互结构。控制台重构需要跨候选、提案、冲突、参数建议、
技能结晶、记忆整理和 worker 状态形成单一工作台，同时继续满足兰台本地优先、单进程部署
和零前端供应链的约束。

可选方案包括：

1. 引入 React/Vite 等构建链；
2. 继续把全部 HTML/CSS/JS 内联在一个 Python 字符串；
3. 使用 FastAPI 托管独立 HTML/CSS/原生 ES Modules，无构建步骤。

## 决策

选择方案 3：新 `/ui` 使用独立静态资源和原生 ES Modules，由 FastAPI 同源托管。

- 不使用 Node 构建、运行时 CDN 或第三方前端框架；
- HTML、样式、API 客户端与界面状态拆分为可直接读取的静态文件；
- API Key 仍通过同源 `X-API-Key` 请求头发送，不进入 URL；
- `/ui` 首先切换为新工作台，`/ui/recall`、`/ui/evolve`、`/ui/pulse`、
  `/ui/vault`、`/ui/map` 保留，按功能对等逐步吸收；
- 案牍聚合与业务操作留在后端 service/API，前端只编排状态和呈现，不复制业务规则。

## 理由

- 保持当前单进程安装与离线部署体验，不新增 npm、构建产物和 CDN 风险；
- 相比 Python 内联大字符串，独立模块更易测试、审阅和演进；
- 渐进迁移避免一次重写召回、质量、星图等复杂旧页面；
- 业务规则集中在后端，可供 REST、MCP 与控制台共享，避免界面与实际语义漂移。

## 影响

- FastAPI 新增同源 UI 静态资源路由；`routes_ui.py` 保留旧页面响应。
- 新增案牍聚合与详情 API；前端按 30 秒轮询并在操作后刷新。
- 旧 UI 测试继续保留，新工作台增加静态资源、交互契约和响应式验证。
- 若未来引入构建链，需新 ADR 说明离线部署、供应链和迁移成本如何处理。
