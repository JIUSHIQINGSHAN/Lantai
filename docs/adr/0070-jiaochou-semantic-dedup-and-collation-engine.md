# ADR-0070: 校雠（Jiaochou）——智能语义去重与知识对齐订误引擎

**日期**: 2026-10-30  
**状态**: Accepted  
**决策者**: 大哥  
**来源**: 针对存量记忆库语义冗余、近义重叠、局部冲突与多路异构去重订误需求。

---

## 背景

兰台记忆在长期运行中，用户交互与多轮摄取会沉淀大量表述各异但内核高度冗余的事实。
既有系统在去重侧存在如下局限：
1. `dedup.py` 仅在候选入库的瞬间单向比较余弦相似度，缺乏面向存量库的全域语义对齐与冗余扫描机制；
2. 缺乏细粒度订误（Refine & Align）动作：仅有粗暴的 `merge`（更新时间戳）与 `update`，无法结构化提炼两个近义事实的差异点；
3. 缺乏专用对齐校验服务：Agent 无法针对传入的两个或多个记忆片段执行精确的语义校勘与订误对比；
4. 归属与隔离纪律：全域扫描与校勘必须严格受行级租户与属主安全隔离保护，订误结果经樊篱（`wrap_as_data`）围栏保护。

---

## 决策

确立「校雠」（Jiaochou）智能语义去重与知识对齐订误体系：

| 维度 | 决策 | 规范说明 |
|---|---|---|
| **命名出处** | 校雠（Jiaochou） | 出自西汉刘向《别录》「一人读书，校其上下，得谬误而差正之，谓之校；一人持本，一人读书，若冤家相对，谓之雠」，喻指多源互校、勘误订正与去重融合；见 [ADR-0013](0013-naming-system.md) 候选池转正，登记于 `CONTEXT.md`。 |
| **校勘对齐模型** | `CollationDiff` 与 `CollationReport` | 统一抽象对比结果：包含共同事实（overlap）、差异点（divergence）、订误动作建议（merge / update / retain_both）与加权置信度。 |
| **存量冗余扫描** | `JiaochouEngine.scan_redundancy` | 扫描租户内活跃记忆，计算高维嵌入语义聚类，识别冗余簇并输出校勘建议。 |
| **双源对齐校勘** | `JiaochouEngine.compare_and_collate` | 输入两条记忆或自然语言文本，逐句勘校其互证与差异，输出结构化订误建议。 |
| **樊篱安全包裹** | 全链路 `wrap_as_data` | 校雠输出的合并文本建议与差异点强制经由 `<memory_data id="...">` 隔离。 |
| **行级租户隔离** | `_check_access` 纪律 | 跨租户跨属主记忆严格隔离，禁止越权校勘与融合，宁 miss 不脏写。 |
| **API 与 MCP 扩展** | REST + MCP 83 工具池 | 落地 `/jiaochou/collate` 与 `/jiaochou/scan` 端点，并注册 `jiaochou_collate` MCP 工具，达成 83 工具里程碑。 |
| **认知上下文切面** | `CognitiveContext.jiaochou_digest` | 当上下文存在近义或冗余记忆时，挂载 `## Semantic Alignment & Collation (校雠 · {count})` 切面。 |

---

## 影响

- 极大降低长程记忆库的膨胀率与近义噪音干扰；
- 形成完整的「摄取初筛 $\to$ 存量全域校勘 $\to$ 双源订误对齐 $\to$ 认知上下文精简」闭环；
- 系统 MCP 工具总数扩充至 83 个。
