# ADR-0017: 记忆 Wiki——digest 升级为持续维护的知识库

**日期**: 2026-08-11
**状态**: Accepted
**决策者**: 大哥
**来源**: [票据 01](../../.scratch/wiki/issues/01-llm-wiki.md)

## 背景

腾讯 TencentDB Agent Memory MemoryKnowledge `engines/wiki/ingest-v2/`：增量维护 +
`overview.md` 综述（LLM 把全部页标题+描述织成叙事）+ `[[wikilink]]` 下钻 + index 渐进式
披露（OKF 先看目录再钻取）。调研见 `docs/research/tencentdb-agent-memory-borrow.md`。

兰台现状：digest 是每日一次性盘点（五项统计），overview CLI 是存量快照——两者都不
回答「记忆沉淀成了哪些可复用的主题资产」；场景聚合（ADR-0012）已有主题分组，但只
活在注入导航里，没有可浏览/可下钻的知识库形态。

## 决策

| 项 | 决策 |
|----|------|
| 页面来源 | 场景（`MemoryScene`）→ 场景页；Skill 资产（`structure.steps` 非空）→ 技能页；单条记忆不进 Wiki（可检索，Wiki 是精选综述层） |
| 产物目录 | `docs/memory-wiki/{index.md, overview.md, pages/}`（`WIKI_OUTPUT_DIR` 可覆盖；与 digest/offload 同模式） |
| 页面形态 | frontmatter（type/title/description/timestamp/member_count）+ 摘要 + 成员记忆（截断）+ 相关场景 `[[wikilink]]`（质心余弦 top N） |
| 索引 | `index.md` 按类型分组（场景 → 技能）稳定排序，标准链接，先看目录再钻取 |
| 综述 | `overview.md` LLM 优先（chat_json，外部依赖可 mock）；失败/关闭 → 确定性综述兜底（统计 + `[[wikilink]]`），零侵入 |
| 增量维护 | `run_wiki_update_once()` 按库状态幂等重写 + 过期页清理（仅限 pages 目录内）；挂接 `mem_sync`（scene + digest + wiki 三件套）+ CLI `scripts/run_wiki.py` |
| 下钻通道 | MCP `wiki_read(slug)`：slug 白名单 + 目录内路径校验（防穿越） |

## 理由

- 腾讯 ingest-v2 是「外部源 → LLM 抽取页」的全量实现（chunker/merge/cascade）；兰台
  的场景/技能已在库里结构化，页面是「物化视图」——零 LLM 也能产出稳定知识库
- 与 digest 互补不替代：digest 管「今天发生了什么」，Wiki 管「沉淀成了什么」；
  mem_sync 一次刷新三件套，Agent 显式触发不依赖定时
- 确定性优先：核心渲染全是纯函数（不 mock 冒烟可测）；LLM 只做综述增强，失败零影响

## 代价

- 页面内容为截断快照（详情仍走检索/记忆工具）；场景重建后需重新 run_wiki 刷新
- Wiki 目录纳入备份/清理策略（与 offload/digest 同）
