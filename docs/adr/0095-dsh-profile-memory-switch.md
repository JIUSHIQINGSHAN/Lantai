# DSH 全局记忆开关

用户希望在设置中集中控制兰台记忆。DSH 当前配置保存一个默认关闭的选择，开启后在已登记文件夹的主对话中按需载入。仅实际 owner 控制入口可以更改这一选择。既有逐对话授权不会迁移。

- 利用 DSH 自带的 Host 存储保存选择。记录包含配置身份与读取范围的摘要。连接、资料归属、工作目录或任务块范围变化后，原选择失效，需要在设置中重新开启。
- 插件保留原有加密 SSH 和严格主机验证。开启后，新建及已打开的主对话从下一次实际请求开始加载。子代理不单独读取。每次读取都核对当前文件夹和资料归属，优先解析已有凭据引用。密钥仅用于当前读取。
- 关闭时停用快照并中止在途读取。保存失败时当前运行实例继续停读，界面说明结果并保留重试。聊天历史和已经发送的模型请求按 DSH 现有规则保留。其他获准查看同一聊天的人可能看到已经加入的资料。
- 设置页用宿主扩展点，加入固定名称、键盘可达的开关和保存反馈。浏览器只接收设置状态与范围摘要。范围与许可由 Host 核实。

此决策取代 ADR-0094 的逐对话授权，继承其中的加密连接、凭据隔离和资料范围校验。
