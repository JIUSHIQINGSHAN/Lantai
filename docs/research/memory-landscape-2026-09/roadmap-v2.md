# 兰台路线图 v2（R14 产出，2026-09-19）

> 依据：20 系统一手核验 + 32 篇论文 + 9 基准 + 15 轮迭代记录（iterations/iter-01..13）。
> 与 2026-09-18 调研主线 A/B/C 兼容，差异在 churn 表中显式列出。**均为建议，不是承诺工期。**

## 定位声明

**兰台 = 面向个人维护与多宿主 Agent 的、全生命周期可治理的本地长期记忆层：唯一把「人工闸门—回滚—注入围栏—状态机遗忘」做成闭环的系统；用操作级自证替代榜单叙事。**

## P0（约 30 天）——可靠性 + 治理兑现

| 项 | 内容 | 验收口径 | 依据 |
|---|---|---|---|
| P0-1 可靠性收口 | 解释/修复已知测试失败，全量门禁 | 当前分支全量无未解决失败；核心函数不 mock 冒烟 | 继承 2026-09-18 主线 A |
| P0-2 撤回/删除四分法 | 纠错/撤回/归档/删除语义分离，覆盖 SQLite/FTS5/Chroma/摘要/缓存/宿主副本 | 确定性用例撤回后禁用命中=0 | iter-12 D23；Governed Shared Memory 原语 |
| P0-3 E1 阶段化评测 | dry-run 拆「提取→闸门→入库→索引→召回→注入」各步成功率与失败归因 | 每步有独立指标+样本数；HaluMem 式阶段归因 | iter-09 E1 |
| P0-4 注入回执链 | 事件链绑定 request/session/turn/memory id，宿主回执证明实际注入 | 受控宿主冒烟中来源可追溯率 100% | 2026-09-18 主线 A + iter-13 |

## P1（约 60 天）——时间主线 + 宿主矩阵

| 项 | 内容 | 验收口径 | 依据 |
|---|---|---|---|
| P1-1 事件时间与时效视图 | MemoryItem 增 event_time（可空+精度标记）；时间窗过滤+当前/历史双视图；迟到更正走冲突裁决 | 30+ 时间/更新用例，当前/历史证据选择正确率 ≥90% | iter-11 D20（P1 首位） |
| P1-2 宿主矩阵 | shell hook 泛化为 Claude Code/Codex/Cursor 钩子适配（MemU/OpenViking 模式） | ≥3 宿主端到端冒烟 | iter-13 D24 |
| P1-3 巩固可信度 | 沉潜/反思产物一律过审；巩固前后快照 | 巩固产物 100% 带提案记录 | iter-08 TRUSTMEM 佐证 |

## P2（90 天+）——影子学习与对外自证

| 项 | 内容 | 边界 |
|---|---|---|
| P2-1 episode 影子→离线消融 | 区分召回/注入/采用/任务完成；≥100 有效样本分层 | 不足不调权；不自动接分 |
| P2-2 RL 影子观察 | 记录记忆操作与结果供离线分析（Mem-α/Memory-R1 路线观察） | **不承诺实现**，RL 不进生产调权 |
| P2-3 操作级自证发布 | E1/E2 指标 + judge 协议公开；LongMemEval-S/MemoryAgentBench 子集作外部锚点 | 不追 LoCoMo 榜；自报分数一律标 claim |
| P2-4 考功/结晶转化率 | 技能结晶、经验→规则的实际转化率公开数字 | 差异化叙事的证据基础 |

## 不做清单（v2 强化版）

不重写 SQLite/FTS5/Chroma；不引入图数据库集群；不先做多智能体联邦；不按召回次数自动晋升；不让自评直接调权；不用衰减替代删除；不把完整对话上传外部评测；不用广告百分比/单榜总分/局部全绿背书质量；**RL 记忆管理不做生产实现承诺**。
