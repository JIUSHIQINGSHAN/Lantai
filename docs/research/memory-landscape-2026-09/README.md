## 目录结构

| 文件 | 用途 |
|---|---|
| `framework.json` | 评测框架：10 个能力维度、权重、评分锚点、各系统得分（随迭代修订） |
| `landscape.json` | 记忆系统全景数据集（目标 ≥30 个系统），每条含一手来源与核验状态 |
| `papers.json` | 论文与基准数据集（目标 ≥25 篇） |
| `iterations/iter-01..15.md` | 每轮迭代的人类可读记录：本轮焦点、吸收的证据、评分变化、决策、开放问题 |
| `iterations.jsonl` | 机器可读的迭代流水（驱动可视化） |
| `charts/*.png` | 迭代过程与最终结果图表（matplotlib 生成） |
| `dashboard.html` | 最终可视化框架：单文件、零外部依赖，内嵌 SVG 图表 + 数据表 |
| `synthesis.md` | 最终综合：方向判断、路线图 v2、定位声明 |

## 迭代协议（15 轮）

**迭代对象**：调研数据集（landscape/papers）、评测框架评分（Lantai 与代表系统的 10 维得分）、方向路线图。每轮必须产生**可检验的增量**（新增证据、评分变化并注明理由、路线图增/改/删），并写入 `iterations.jsonl`；空转轮次视为无效。

| 轮次 | 类型 | 焦点 |
|---|---|---|
| 01 | setup | 评测框架 v1 + 数据骨架 + 基线评分（继承内部文档） |
| 02–07 | survey | 分批吸收外部调研：头部系统 → 新兴方案 → 平台/框架原生 → 论文与基准 |
| 08–09 | survey | 论文纵深（巩固/遗忘/记忆管理范式）+ 基准与评测方法 |
| 10–13 | synthesis | 主题综合：分类学与生命周期 / 时间与冲突 / 治理与安全 / 接入与评测策略 |
| 14 | synthesis | 路线图 v2 收敛（收敛指标：评分增量与路线图 churn 双下降） |
| 15 | freeze | 图表、dashboard、最终简报；完成度审计 |

## 评分记法

- 维度得分 0–5（步长 0.5），锚点见 `framework.json`；每个非零分须挂证据引用（内部 ADR 或外部来源编号）。
- 「继承分」：仅依据内部文档未经本轮验证的得分，标 `inherited: true`；被外部证据推翻时降分并记录。
- 收敛指标：`score_delta_sum`（本轮各维 |Δ| 之和）与 `roadmap_churn`（增/改/删条数）。

## 证据纪律

- 一手来源：官方 README/docs、arXiv、ACL/官方博客。二手转述只作线索，不入台账。
- stars/分数类数据注明「检索日期 + 页面实际数字」；厂商自报基准分不横比、不作可复现结论。
- 动态内容仅代表检索时点（2026-09-19 前后）。
