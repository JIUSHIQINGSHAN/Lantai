## P1-1（已修）graph_expand 联想面漏出被取代旧值

**位置**

- `lantai/cognition/late_correction.py:73-81`：`apply_supersede_correction` 写 `MemoryEdge(source=new, target=old, relation="supersedes", confidence=0.9)`，旧记忆保持 `status=active`，只标 `lifecycle_status=superseded`。
- `lantai/retrieval/graph_retriever.py:115`：贯珠邻居判定只看 `neighbor_item.status != "active"`，不看 lifecycle。
- `bc0afb5c` 只在 `graph_augmented_search` 末尾对 `primary_results` 调了 `_apply_supersede_guard`，`associated_memories` 原样返回。

**为什么前面的测试没抓到**：票 13 的测试用 `top_k=5` + 宽问句，新旧两条都进了初筛，旧值作为种子已在 `visited` 里，图遍历不会再把它当邻居展开。只要旧值没进初筛（`top_k` 小，或问句只命中新值），它就会作为新值的 1 跳邻居回来。

**复现（修复前，master `8175a745`）**：用票 13 测试同一个 `corrected_env`（"住武汉" 被更正为 "住荆州"），调 `routes_search.search_graph_expand`：

- `query="用户的地址是哪里", top_k=1`
- `query="现在住在荆州", top_k=5`
- `query="荆州", top_k=5`

三次 `primary_results` 都只有 `mem_new`，`associated_memories` 都出现：

```
{'memory_id': 'mem_old', 'hop': 1, 'via_memory_id': 'mem_new', 'relation': 'supersedes',
 'edge_confidence': 0.9, 'content': '用户的地址是武汉，在光谷上班', ...}
```

即 primary 刚丢掉的旧值，在同一响应里换个字段又回来了，而且没有 "已更正" 标记。

**影响面**：REST `POST /search/graph_expand` 与 MCP `graph_expand_search`（`lantai/cli/mcp.py:2108`）。`graph_expand_search` 不在 `HERMES_CORE_TOOLS` 默认核心集里，所以按默认档装的 Hermes 日常注入链路不受影响；`LANTAI_MCP_PROFILE=full` 或直接调 REST 时受影响。

**修法**：`graph_retriever.py` 新增 `_guard_associated_superseded`（245 行起），在 `graph_augmented_search` 第 5 步对联想面套与 `_apply_supersede_guard` 同一口径的闸：

- 只动 `lifecycle_status == superseded` 且 `superseded_by` 非空的记忆邻居（批量一次查询 lifecycle）；
- 问句不带回看词，且取代它的新记忆在本次响应里（primary 或联想面）→ 丢掉；
- 否则保留，`content` 前加 `[已更正：YYYY-MM-DD 起不再成立，仅作历史]`（复用 `supersede._superseded_marker`、`_RETROSPECTIVE_RE`，日期口径一致）；
- 完璧事实条目（`lane == "fact"`）不在本闸范围；
- 开关沿用 `SHELL_HOOK_SUPERSEDED_GUARD`，关掉即逐字旧行为；查询异常时原样返回，不拖垮检索；不改入参、不写库。
- 图遍历本身（种子、跳数、边）一行不动。

**测试**：`tests/test_graph_expand_associated_supersede_guard.py`，12 个：

- 集成 6 个（真库 + 真更正链，直调 REST 路由与 MCP handler）：top_k=1 当前问句、只命中新值的问句、响应里不得出现旧正文、回看问句保留并带标记、开关关闭逐字返回（对照组）、MCP handler 同契约；
- helper 单元 5 个：新值不在场时保留并带日期标记、新值在联想面时丢旧值、不改入参、非取代条目与事实条目原样、空列表与不存在 id 原样；
- 标记日期口径 1 个。
