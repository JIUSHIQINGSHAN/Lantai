单位向量上 squared-L2 = 2 ×（1 − cos），正好是余弦距离的 2 倍。换算到生产库（前提是 bge-m3 存进去的向量是单位长度，建议你在冷备 bundle 上算一下模长确认）：

- 向量召回截断：设计意图是余弦 > 0.2 都留下，生产上实际要余弦 > 0.6 才留下。余弦 0.2 到 0.6 之间的记忆在生产上进不了向量通道，只能靠 FTS/BM25 那一路。
- 查重：fastpath merge 0.90 实际要余弦 ≥ 0.95；提取路径 merge 0.95 实际要余弦 ≥ 0.975；update/中带 0.65 实际要余弦 ≥ 0.825。生产上判成「重复」「更新」的门槛都比设计高，更容易插入近似重复的新记忆。
- 评测和生产不是同一套行为：CI 和测试新建的库是余弦，测出来的召回和查重效果不能直接代表你每天用的那个库。

**为什么一直没被发现**：集合标签写的是 cosine，所有测试和评测都新建库（真余弦），只有打开 2026-07-30 以前建的那个库才会走 L2。直到这次迁移工具去读 segment metadata 才露出来。

**两个改法，选一个（本 PR 不动代码）**

- **A. 生产库改成真余弦（推荐）**：迁移工具 import 时允许显式 `--target-space cosine`，用 bundle 里的原向量重建 cosine 索引，不需要重新 embedding。验收照旧用 float64 oracle，只是距离基准换成余弦。好处是生产、新装、CI、评测从此是一套语义，阈值不用动。代价：需要再做一次冷备迁移；cosine 重建有你已经测到的至多 1 ULP 舍入（`--max-vector-ulps 1`）。
- **B. 代码按实际空间换算**：`ChromaVectorStore` 读出集合的实际 `hnsw.space`，`search()` 返回统一的「余弦距离」（L2 且单位向量时除以 2），`hybrid.py` 和 `dedup.py` 不用改。好处是不用再迁移；代价是要先确认向量确实是单位长度，否则换算不成立，还得加一条「非单位向量拒绝换算」的守护。

不管选哪个，建议都加一条最小守护：服务启动时记下实际 `hnsw.space`，在 `/health` 或悬镜面板显示出来，不是 cosine 就报警。这样以后不会再靠迁移才发现。

**你自己怎么验收**：选 A 的话，迁移完用 `ChromaVectorStore()` 重开目标库，确认集合配置是 `cosine/930`；再拿一条已知相似的记忆查一次，看 `trace` 里 `vector_search.score_range` 是否落在余弦的合理区间。选 B 的话，在 L2 库和 cosine 库上用同一个查询，`search()` 返回的距离应该一致（误差在 1e-6 以内）。

**复现脚本**（在安装了本项目锁定依赖的虚拟环境下运行；无需 `API_KEY` 或模型服务，不碰任何真实库，只用临时目录）：

```python
import tempfile

import chromadb
import numpy as np

rng = np.random.default_rng(7)
D = 1024
q = rng.normal(size=D)
q /= np.linalg.norm(q)
r = rng.normal(size=D)
r -= r.dot(q) * q
r /= np.linalg.norm(r)
targets = [0.97, 0.95, 0.9, 0.85, 0.8, 0.7, 0.6, 0.5, 0.4, 0.3, 0.2]
vecs = [(c * q + np.sqrt(1 - c * c) * r) for c in targets]
ids = [f"cos_{c}" for c in targets]
with tempfile.TemporaryDirectory() as d:
    client = chromadb.PersistentClient(path=d)
    for space in ("l2", "cosine"):
        coll = client.get_or_create_collection(
            name=f"demo_{space}", configuration={"hnsw": {"space": space}}, embedding_function=None
        )
        coll.add(ids=ids, embeddings=[v.tolist() for v in vecs])
        res = coll.query(query_embeddings=[q.tolist()], n_results=len(ids), include=["distances"])
        print(space, [round(float(x), 3) for x in res["distances"][0]])
```
