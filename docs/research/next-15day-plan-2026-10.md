## 三、主线票

### 票 A：E1/E2 正式跑测（Day 3–5）

- **Day 3 上午：先修替考后门**——`staged.py:496` 锚点缺席时 `or indexed[:1]` 替考报绿（已逐字核实）。修复=锚点结果带 sid 证据、f1 缺席报 `redirected:<实际拦截段>`；判定代码改动过变异门禁（≥3 变异体）。
- **对表落 fixture**：修复后的 harness 跑预埋锚点，预期标签**外置出 staged.py**（code/data 分离），对表脚本产出带证据字段（獬豸拦截日志/sid）的标签数据文件，人只审 diff；翻转条数与说明一一对应、其余数字零漂移。旧标签制定于 v0.23.0 之前——fence_escape 载荷被獬豸前置拦截是预期中的产品进步。
- **正式跑测**：提取段真 LLM（模型名/版本/base_url/温度钉入报告）+ 替身 CI 对照各一轮；**提取段跑 3 报一致率**（供应商侧非确定性，读者第一问）；产出 `docs/benchmarks/staged-eval-report-2026-10.md`。
- **信息披露口径**：公开报告只报 `redirected(前置控制)` 计数+打码样例；完整 sid 证据留内部 harness——防线分层图不外送。
- **量级**：3 天（含修复半天）。前置：票 G。

### 票 B：LongMemEval 外部锚点（Day 6–9）

- **Day 1 并行**：数据集后台下载（HF 直连锁 revision commit SHA；走镜像才做 SHA256↔LFS oid 校验）；版本选型 V2（Apache-2.0，2026-05）vs cleaned-S（MIT），判据含「有无可引用参照数字」，理由入报告。原 v1 已被作者弃用。
- **预注册**：种子+题目 id 清单先 commit；**运行时断言预注册 id 集 ⊆ 下载数据集 id 集**（不满足起跑即响亮失败）；缩题只减不换（防挑易题）。
- **Day 6 pilot 先行**：灌 1 题真 embed 实测吞吐/429 率/单题费用，×3 外推定 50 或 25 题；预注册清单同步改。429 指数退避+限并发。
- **灌库双闸**：独立 `LANTAI_DATA_DIR`+入口断言≠生产路径；只走正式 API 单通道不停服；脚本 grep 禁 `chroma`/`Session` 直连 import；API 启动横幅打印评测库路径供对表。**白天人在时灌、夜间不排**（Windows 更新重启是头号单点，逐题 checkpoint 把损失压到 ≤1 题）。
- **checkpoint 防半题**：题内 chunk 进度落盘；续跑先对账（应灌 N 实测 M→清题重灌——勘合自动指纹键只护 600s，隔夜续跑已出窗）；半题检测写成不 mock 冒烟测试；checkpoint 绑 `config_hash`，聚合前断言每题恰属一个配置（防消融跨配置污染）。
- **口径**：主指标=会话级 distinct-session recall@2/@5（金标 session 是否出现在 top-K 条映射回的会话集中）；gate 跳过=miss 计入全题分母，条件召回附报；五种题型按 S 集分布定比分层，层级数字标「描述性」，abstention 单列（recall 不定义）。
- **映射保真度审计**：打分前先跑覆盖审计（每金标 session ≥1 条可检索条目），覆盖率与 recall 同报——仪器未校准先开测，完美检索也会被静默记 miss。
- **三配置消融（只在真 embed 档）**：vector-only / BM25-only / 四路全混合——给「0.6+0.25+…」权重设计拿第一份公开实证；消融是测量不是调参。
- **CI 档=harness 复现性验证**：确定性 embed 单一真源（仓内现并存 512/1024/8 三套，收成一套）、维度入报告、独立 collection；同种子重跑逐位一致；跨档只并列展示禁比较。
- **长跑可见性**：脚本状态落盘+完成/失败 Windows 通知+「看进度」命令——非技术维护者不盯黑箱。
- **诚实边界**：英文语料如实标注；只测⑤召回段（无 judge 无生成）；报告明示不代表全链路；数据 gitignore、评测本地跑不入 CI；subprocess 传最小 env。
- **量级**：4 天。

### 票 C：自证发布文档（Day 10）

## 八、风险与诚实性声明

1. **英文语料 vs 中文优化**：首轮数字不做预期、测出多少冻结多少；不做语种借口也不做突击调参。
2. **纯检索模式只覆盖⑤召回段**：外部锚点仅验证召回，全链自证以 E1 阶段表为准，两份证据各说各的范围。
3. **episode 样本可能仍不足**：影子接线+盘点照交，样本数如实标注——dogfooding 起用后数据开始积累，消融推下窗口不等于失败。
4. **单机单点**：Windows 自动更新重启/代理断/429——逐题 checkpoint+白天灌库+pilot 外推三道缓解；最坏缩 25 题，预注册同步改。
5. **熔断误杀**：全形模式+转待审（不静默丢）+先影子后执法三重校准；dogfooding 期间维护者可在悬镜控制台看到转待审条目并裁决。
6. **数字可复现性**：真 embed 档依赖本地 key（报告注明环境/模型/费用），CI 复现档只证 harness 确定性——两档预期不同数字，报告写明。
