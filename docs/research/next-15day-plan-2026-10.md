## 三、主线票（P2 自证与影子盘点）

### 票 A：E1/E2 正式跑测出第一份阶段化报告

- **做什么**：用既有 `scripts/run_staged_eval.py` 对锚点语料跑正式一轮（提取段走真 LLM 本地跑 + 替身跑 CI 对照各一轮），产出 `docs/benchmarks/staged-eval-report-2026-10.md`：六段各 samples/success_rate/failure_buckets；E2 确定性用例结果并入附录。
- **跑测前必须先做「锚点对表」**：E1 预埋锚点的预期标签制定于 v0.22.0（票 03 交付时）；此后 v0.23.0 上线了獬豸写入侧注入闸（`lantai/ingestion/dialogue.py:86` 已接线）——**fence_escape 预埋载荷可能被獬豸在摄取段前置拦截，到不了预想的注入段**。正式跑测前先单跑四条预埋锚点核对实际归属；若归属因产品进步而变（注入文本在写入侧被拒是更好的结果），更新 harness 预期标签并留说明——绝不为了「锚点按旧标签归段」而绕开獬豸。
- **验收**：预埋锚点各归正确段不串段（对表后的标签为准）；对照校验——既有 94 样本召回层指标与两层基线数值一致；**提取段 LLM 钉定**（模型名/版本/base_url/温度入报告，E1 规范确定性原则的落实）；报告每页标 claim 属性「本地小样本自证，不外推」。
- **纪律**：真实闸门/入库/索引/召回/注入段严禁 mock；报告不自动调参。
- **量级**：2 天（Day 3–5 内，前置票 G）。

### 票 B：LongMemEval 子集接入（外部锚点，纯检索模式）

- **Day 6 先做版本选型**（红队审阅新增）：原 v1 数据集（`xiaowu0162/longmemeval`）**已被作者标记 deprecated**，替代品为 `longmemeval-cleaned`（S 集，MIT）；2026-05 又出了 **LongMemEval-V2**（HF `xiaowu0162/longmemeval-v2`，Apache-2.0，「Toward Experienced Colleagues」）。两版许可均为白名单级（不复现 HaluMem 陷阱）。选 V2 还是 cleaned-S 的理由写进报告；数据集下载 Day 1 就后台启动（本机代理状况多变，HF 直连不稳走 hf-mirror 备胎）。
- **摄取模式与成本预算**：按会话**原文直存**（不经 LLM 提取）——纯检索口径干净、成本可控，且金标映射靠它：每条 verbatim 的 provenance 记录来源 session id，recall@K 才有判定依据（兰台检索单元是记忆条不是会话，映射必须显式设计）。量级：50 题 × ~115K tokens ≈ **5.75M tokens 一次性 embedding**，预估数小时墙钟 + 个位数人民币 API 费；**按题 checkpoint 断点续跑**（崩在第 37 题不从头来；勘合幂等兜底重试）。报告明示：此数字不代表全链路（提取段未参与）。
- **禁用 oracle 变体**：数据集自带只含证据会话的 oracle 版——用它等于考前发答案，必被质疑作弊。只用完整 S 集（含干扰会话）。
- **预注册防 cherry-pick**：种子与 50 题题目 id 清单在**首次正式跑测之前先 commit**（时间戳证据）；先跑后选种即作弊，纪律红线。
- **指标**：recall@2 / recall@5 为主指标；**按五种题型分层报告**（information_extraction / multi_session_reasoning / temporal / knowledge_update / abstention）——abstention 题金标会话不存在，recall 不定义，单列如实处理不混入总分；**gate 跳过率一并报告**（trace=true 逐题记录闸门决策）——兰台卖点是「无关查询零检索成本」，若闸门误杀合法记忆查询，这是自证最该抓的真问题，藏起来才是漏洞。
- **通道消融（新建议采纳）**：同一份已灌数据跑三配置——vector-only / BM25-only / 四路全混合。「0.6 向量 + 0.25 BM25 + …」的权重设计此前从未有公开实证，这是零边际成本拿到架构证据的机会；消融是测量不是调参，与「首轮冻结」纪律不冲突。
- **双档复现**：真 embedding 数字为「本地冻结档」；另用确定性本地 embed（票 F 后与真实同维）跑同 50 题入「CI 可复现档」——回应「你的核心数字别人跑不出来」的质疑。
- **stretch**：temporal 题型子集加跑 as_of 配置（更漏亮剑，单独标注，不动主基线）。
- **验收**：预注册 commit 先于正式跑测；50 题全部跑完无静默跳过（失败题逐条列原因）；oracle 变体零引用；报告含分层表 + gate 跳过率 + 三配置消融 + 双档数字；脚本入仓、数据 gitignore。
- **量级**：4 天（Day 6–9，15 天内最重一票）。
- **MemoryAgentBench 子集**：stretch 目标——仅当许可与数据可得性在实施时确认才加；否则报告如实标 `not_applicable`（不编造，E1 规范扩展位纪律）。

### 票 D：episode 影子接线与消融工具（P2-1 第一步，红队审阅后重定义）

- **红队实锤前置事实**：`episode_credit_map` 在检索/打分侧**零消费方**（2026-10-08 grep 实证：retrieval/ 与 hybrid 无任何引用）——原计划「带/不带 credit 跑检索对比」是空转，跑出来两组数字必然一模一样。先接线，消融才有东西可比。
- **做什么**：第一刀**影子接线**——episode credit 作为检索加权信号以 shadow 开关接入（`EPISODE_CREDIT_ENABLED` 默认 false，不动线上行为，ADR 记决策）；第二刀只读盘点脚本（线上存量、有效样本数、credit_map 分布）；第三刀消融脚本——同一批锚点语料开关 credit 各跑一遍对比。
- **诚实边界**：有效样本 <100 时报告标「样本不足，消融结论 unavailable」——工具先落地，数字等数据积累（P2-1 原口径 ≥100 分层样本）；样本来源见「待拍板」第 4 条 dogfooding。
- **验收**：开关默认关闭时检索行为与现状逐位一致（回归断言）；盘点脚本对空库不炸（0 样本合法输出）；消融脚本确定性可复跑。
- **量级**：2 天（Day 11–12）。

### 票 E：考功/结晶转化率只读报告（P2-4 第一步）

## 八、风险与诚实性声明

1. **英文语料 vs 中文优化**：LongMemEval 全英文，兰台的 jieba/FTS trigram 检索对英文同样工作但未针对优化——首轮数字不做预期、测出来多少冻结多少（预设「预期偏低」本身就是无数据断言），不做语种借口也不做突击调参。
2. **纯检索模式只覆盖⑤召回段**：对外的自证报告须写明「外部锚点仅验证召回，全链自证以 E1 阶段表为准」，两份证据各说各的范围。
3. **episode/考功存量可能不足**：两票的输出可能是「工具落地 + 标 unavailable」——这是合格交付（宁 miss 不脏写），不是失败。
4. **评测脚本依赖本地 key**：票 B 评测本地跑不入 CI，CI 只验脚本语法、单元测试与 CI 可复现档；报告注明运行环境、模型与费用。
5. **网络与下载风险**：本机代理状况多变（有保质期的既有教训）；264MB 级数据集下载走后台 + hf-mirror 备胎，Day 1 启动不占主线。
6. **闸门误杀是特性内的风险**：LongMemEval 问句若被相关性闸门判为社交/闲聊而跳过检索，如实计入 gate 跳过率指标——它既是分数损失也是产品自知的输入，两头都要。

## 九、红队审阅记录（2026-10-08，进攻方视角）

以「这份计划会怎么被攻破」为题自查，三个实锤漏洞（均已修订进正文）：

1. **票 D 是空转的**——grep 实证 episode credit 在检索打分侧零消费方，原「带/不带 credit 对比」必然输出两组相同数字。修订：先影子接线（默认关）再消融。
2. **自家獬豸闸会吃掉 E1 预埋考题**——fence_escape 锚点的预期标签制定于 v0.23.0 之前，注入载荷现在会在写入侧被前置拦截，到不了预想的注入段。修订：跑测前先锚点对表，标签随产品进步更新且留痕。
3. **考卷选型写在旧世界上**——原 v1 数据集已被作者弃用（deprecated），2026-05 已出 LongMemEval-V2（Apache-2.0）；计划原引的 HF 路径是过渡版。修订：Day 1 版本选型 + 后台下载；同时确认两版许可均白名单级（MIT/Apache-2.0），HaluMem 陷阱不复现。

防质疑加固（均采纳）：预注册种子与题目清单（commit 时间戳防 cherry-pick）、禁用 oracle 变体（防作弊高估）、金标 session→记忆条映射显式化（provenance 记 session id）、双档复现（CI 确定性档 + 本地真 embed 档）、gate 跳过率一等指标（防「你们的闸门吃了考卷却不说」）、成本与断点续跑预算、票 G 从手挑清单改为全量冻结（护栏枚举教训的套用）。

新增建议待拍板：dogfooding（第 4 条）——样本池没人灌水的问题，装到维护者自己机器上 15 天就解决了。
