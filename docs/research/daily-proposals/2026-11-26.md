## 一句话结论
回答层评测只量“记忆有没有覆盖要点”，没有“不带记忆”对照，量不出“记忆让原本能答对的题答错”。建议补一把尺子：记忆致损率。

## P0 损益簿——回答层评测加“无记忆对照”，量出记忆致损率 MID 与最优注入条数（M）

### 动机
- `lantai/eval/answer_quality.py` 的 `rule_judge` / `llm_judge` / `compute_answer_metrics` 只算“要点是否出现在召回正文”的命中率，注释自称“保守下界”。它回答不了：同一道题，不注入记忆是否本来就能答对？注入后是否反而答错？
- `lantai/retrieval/hierarchical.py:161` 的 `rerank_by_information_density(max_items=5)` 条数写死为 5，没有依据说明 5 对当前读者模型是否合适。
- 11-18「辨新」已提出 Contamination@k（陈旧污染），那是单一失败模式；MID 是总账，把所有“记忆帮倒忙”都计入。

### 外部依据（均已打开页面）
- arXiv:2611.14320（2026-11-10 提交，ACL ARR 审稿中）：定义 memory-induced degradation，即“不带记忆能解、带记忆反而失败”，并报告其可被降低。https://arxiv.org/abs/2611.14320
- arXiv:2611.26361（2026-11-19 提交，IAAI 2027）：“合适的记忆量取决于模型，不取决于记忆”；弱模型全量 199 条 51.2%，精选约 29 条 55.4%，强模型则越多越好。同文还提到巩固时来源信息被静默丢弃、吞掉 API 错误后日志看似正常。https://arxiv.org/abs/2611.26361

### 设计要点
1. 在评测 runner 中为每道题跑两臂：A 臂不注入，B 臂按现有流程注入。同一读者、同一提示。
2. 新指标：MID = 「A 对 B 错」的题数 / A 对的题数；同时报告增益 = 「A 错 B 对」占比；净收益 = 增益 − MID。按类别（更正、撤回、偏好、时序）分列，与现有 by_category 对齐。
3. 条数扫描：k ∈ {1,3,5,8,12}，各出 MID 与净收益曲线，决定 `max_items` 是否改为可配置、是否按读者模型分档（后者只做记录，不立即改行为）。
4. 判官诚实：A 臂没有召回正文，必须用答案判官（llm_judge 或规则对要点），不能复用“召回覆盖”口径；离线 CI 用确定性的假读者（按注入内容里是否含正确/过期值作答）验证指标计算本身。
5. 结果只写报告，不接门禁；先出尺子，再决定是否调参（沿用 11-19「先出尺子」思路）。
