## 结论

票 90 让 `shell_hook.py` 的**读侧**按 `LANTAI_HOOK_USER_ID` / `LANTAI_HOOK_ROLE` 检索，但**写侧** `_handle_dialogue` 仍调 `ingest_dialogue(text, session_id=, turn=)`，不传属主，候选落 `user_id="default"`。promoter 把候选的 `user_id` 原样抄到 `MemoryItem`。非 admin 的读侧过滤是 `user_id == 配置值 OR IS NULL`，所以：

**只要把钩子属主配成 user 档（例如 `LANTAI_HOOK_USER_ID=alice`），钩子从对话里学到的每一条新记忆，钩子自己都检索不到、注入不了。**

未配置时（默认）行为不受影响：读写都是 default 语义，这也是 CI 一直绿的原因。插件模式和 CLI 模式走的是同一个 `_handle_dialogue`，两边都有这个问题。
