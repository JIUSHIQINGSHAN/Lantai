# 兰台长跑战略备忘录：无限续杯计划（The Sustainable Marathon Engine）

> **生效日期**：2026-10-28（承接 v0.26 完璧窗口全自主收口）  
> **战略主旨**：告别「脉冲式冲刺、疲劳性堆栈」的开发消耗，确立一套**高韧性、低维护摩擦、自愈自证**的长期演进稳态。

---

## 一、战略本质：什么是「无限续杯」？

在开源 Agent 记忆赛道，绝大多数项目往往经历「高调起跑 $\rightarrow$ 架构膨胀 $\rightarrow$ 维护疲态 $\rightarrow$ 历史债务压垮」的宿命。  
**兰台的「无限续杯计划」**不是无休止地追求庞大的功能清单，而是将工程演进设计为一套**自闭环、自供血、自我免疫的飞轮**：

1. **零负罪感长跑（Frictionless Rhythm）**：
   - 坚持 **两周一窗口（14~15 天）** 自然节拍，每个窗口聚焦 1~2 个高价值核心突破。
   - 无论何时中断，代码库始终处于随时可交付、门禁全绿（0 failed）、文档一致的定态。
2. **内生自愈力（Self-Healing Immune System）**：
   - 依赖纯 SQL `health_scan`、Daily Digest、水位控制与反思蒸馏，让系统具有夜间自清洁能力。
   - 脏数据、过期条目、未决冲突在后台自动显影并提案化，而不是累积成系统毒瘤。
3. **真实自证（Evidence-Driven Engineering）**：
   - 不跟风刷排行榜，以操作级自证（E1/E2 指标、LongMemEval 覆盖率 1.00、MemProbe 稳定性）作为代码有效性的唯一锚点。

### 1. v0.26.0「完璧（Wanbi）」——基底固化（已收口）
- **核心成果**：打破二元关系碎片化枷锁，落地 `fact_atomic` 与 `fact_entity`（v31 迁移）；抽取端保整约束生效；反思健康透出与端到端冒烟通过；全量 2216 测试 0 失败。

### 2. v0.27.0「贯珠（Guanzhu）」——全景打通（当前就绪窗口）
- **主题**：**贯珠串联，完璧归心**（《汉书·景十三王传》「如贯珠焉」）。
- **攻坚维度**：
  - **Hybrid 检索融合**：把 `fact_atomic` 纳入统一召回面，检索涉及多实体时优先输出完整原子事实块；
  - **贯珠图谱二度扩散**：摒弃传统脆弱的二元边（Binary Edge），沿 `fact_entity` 共同包含的原子事实进行语义多跳联想；
  - **笔削四分法联动**：事实原子的就地更正、撤回（retract）止召回与级联清理。

### 3. v0.28.0「稽古（Jigu）」——时态检索与历史快照
- **主题**：**考订古今，时态立心**（《尚书·尧典》「曰若稽古」）。
- **攻坚维度**：
  - **as-of 时态查询引擎**：支持检索任意历史时点（`as_of="2025-06-01"`）的真实记忆视图，绝不让未来知识污染历史回放；
  - **迟到更正的时态消解**：用户事后补充历史更正事实时，自动在时间轴上重排历史，而非简单覆盖。

### 4. v0.29.0「磨勘（Mokan）」——价值转化与自愈自证
- **主题**：**磨勘功过，自愈长青**（宋代审官院核验官员功绩）。
- **攻坚维度**：
  - **Episode 信用实测消融**：基于日常使用（dogfooding 水源）积累的真实回执，完成 `score × (1 + 0.1·tanh(credit))` 的离线消融验证；
  - **考功与结晶转化率透出**：量化统计从任务失败记录转化为信念、规则、结晶的转化率与实际规避风险率。

## 三、长期稳态运行铁律（The Core Guardrails）

为保证长跑绝不跑偏，确立以下四道不可动摇的底线铁律：

1. **测试纪律（Testing Discipline）**：
   - 核心业务函数（被 API、worker、service 调用的存储/检索/决策函数）**必须至少有一个不 mock 内部逻辑的冒烟测试**（使用最小输入直调真实内部逻辑）。
2. **数据纪律（Data Integrity）**：
   - **宁 miss 不脏写**：置信度不足或存在格式歧义的内容，绝不凭空臆造或自动抹平，一律进待审队列或记录审计日志。
3. **架构纪律（Architecture & Naming）**：
   - 遵循 ADR-0013 命名规范，新概念与版本代号必须出自传统典籍意象，名实相副，且**必须先登记 `CONTEXT.md` 词汇表后方可使用**。
4. **发布纪律（Release Discipline）**：
   - 严格遵循发布门禁 `scripts/release_check.py`，全量单测 0 failed，CI lint clean；**最终打 tag 与 push 永远是人工闸门**。
