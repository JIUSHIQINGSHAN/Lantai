## 一、通用质量铁律（每项必守，不满足不入库）

1. **决策留痕**：涉及行为/语义变更先出 ADR（本计划预计 ADR-0022/0023/0024），新命名登记 CONTEXT.md（ADR-0013 R4）。
2. **测试纪律**（AGENTS.md）：核心函数必须有**不 mock 冒烟测试**——真实构造最小输入直调（允许 mock：外部网络 LLM/embedding/rerank、文件系统副作用；不允许：跳过被测函数内部计算）。
3. **回归门禁**：任何合并前 `pytest tests/` 全绿 + `run_forgetting_quality.py --check` PASS。
4. **发布门禁**：`release_check.py vX.Y.Z` 全 PASS 才进入人工闸门；**push tag 由维护者执行**（Agent 只检查/准备）。
5. **文档同步**：每项收口登记 CHANGELOG + 相关 ADR/CONTEXT/README。
6. **宁 miss 不脏写**：拿不准的判定/块/阈值一律保守——进提案待审、留空、延长观察窗，不拍脑袋。

  3. `scripts/calibrate_reflection.py` → 校准报告（`docs/memory-quality/reflect-calibration-2026-08-1x.md`，生成报告入库随 ignore 白名单规则）；
  4. 对标 dry-run 推荐，落地终值：`REFLECT_IMPORTANCE_POOL` / `REFLECT_AUTO_APPLY_CONF` / `REFLECT_MIN_CONFIDENCE`；
  5. `REFLECT_STALE_SCAN_ENABLED`（R4/R5）是否开启以数据为依据，无依据保持 False。
- **验收 DoD**：① 校准报告留档 ② settings 终值变更 + 依赖断言同步 ③ 全量测试绿 + 评测门禁 PASS ④ CHANGELOG 登记。

### B. 底本闭环（ADR-0021 follow-up）

- **B1 注入端**：`scripts/shell_hook.py` 新增 `--checkpoint` 请求类型（serve 模式消息协议扩展）——返回 `inject_checkpoint_context()` 文本；**独立通道（Q2 已决）**：会话启动注入、预算与检索预算（SHELL_HOOK_MAX_TOTAL_CHARS）解耦，不进每轮召回预算。
- **B2 插件端**：Hermes 插件（hermes-plugin/lantai-hook/）会话首轮 `pre_llm_call` 调 checkpoint 通道注入；`on_session_end` 后按会话缓冲构建五段块调 `checkpoint_write`——块来源规则：末条 user 消息=在做；「下一步/工作区」有明确指向才填；决策句式（"决定了/就按…"）才填决策；**拿不准的块留空（宁 miss）**。
- **ADR-0022**：注入形态（独立通道 + 消息协议扩展）+ 预算边界 + 插件块来源规则。
- **测试**：checkpoint 通道处理函数纯函数不 mock（构造 serve 消息直调）；插件侧 mock 子进程（外部进程）。
- **验收 DoD**：① Hook 注入含 `[Checkpoint · 上次会话]` 段 ② 跨会话重启后首轮可见 ③ 子进程失活静默降级（返回空，插件不炸）④ ADR-0022 + 测试 + CHANGELOG。

## 四、v0.15.1：C1 + C2

### C1. 去重锚点比不对称修复（ADR-0019 已知限制）

- **问题**：锚点比 = 共享锚点 / 旧文本锚点（非对称），old⊆new 时比值 1.0——「数据库使用SQLite」→「…并且迁移到了PostgreSQL」被判 merge，扩展事实被吞（PostgreSQL 非值类不产生新增值）。
- **方案（Q3 已决）**：新增**实质新词信号**——新内容锚点中非停用/非值类的新增实质词数 ≥ `DEDUP_EXTRA_ANCHOR_LIMIT`（默认 2，settings 可配）时，即使无新增值也走 **update 提案**（有刹车，不吞内容）。**不扩技术名值类**（列表漂移，宁 miss：错判最坏进提案由人工裁决）。
- **ADR-0023**：信号定义、阈值默认、与 36 对回归集兼容性、扩展对测试。
- **测试**：36 对回归全绿 + 新增扩展对（old⊆new 型）断言 update；纯函数不 mock。
- **验收 DoD**：① 回归集不回归 ② 扩展对正确进提案 ③ 全量绿 + 门禁 ④ ADR-0023 + CHANGELOG。

### C2. salience 单字否定对 LLM 兜底（ADR-0020 已知限制）

- **问题**：jieba 并词（"我会"→一词、"我是"→一词）使是/不是、会/不会、能/不能等词级互斥不可靠，默认已排除。
- **方案（Q4 已决）**：新增 `check_negation_pairs`——token 级子串探测**候选**否定冲突（是↔不是 等），命中**不落硬规则**、转 LLM 矛盾检测（`check_contradiction`）；确定性兜底不可靠时宁 miss（LLM 失败返回不冲突，维持现状）。
- **ADR-0024**：候选探测规则、LLM 裁决接线、与 check_antonyms 分层。
- **测试**：探测纯函数不 mock（"开会" 不命中、"我会游泳"vs"我不能游泳" 命中候选）；裁决接线 mock 外部 LLM。
- **验收 DoD**：① 候选命中不误伤（词边界）② LLM 裁决降级安全 ③ ADR-0024 + 测试 + CHANGELOG。
