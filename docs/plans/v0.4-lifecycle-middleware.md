# Lantai v0.4 设计与交付规范：分支统一、知识生命周期与认知中间件

> **版本**：v0.4  
> **定位**：从记忆系统迈向「认知运行时」（Cognitive Runtime）的核心收敛里程碑。

---

## 1. 架构六层统一拓扑

本次重组收敛了散落模块与分叉分支（master + rena 司天），正式确立系统六层职责：

`	ext
Lantai
├── cognition/      ← 怎么理解：Evidence, Pattern, Belief, Rule, Principle, Conflict, Reflection, Context, Lifecycle(知命), BLB
├── memory/         ← 记住什么：Retrieval, Vector, FTS5, BM25, Graph(贯珠), Decay, Storage
├── evolution/      ← 怎么进化：Reflector(LLM curator), Promotion, Demotion, Supersession, Checkpoints
├── runtime/        ← 怎么影响 Agent：Middleware(润物), Decision Trace(直断), Outcome, Feedback
├── observability/  ← 怎么感知运行：MetricsCollector, TelemetryMiddleware, RecallReport
└── ops/            ← 运维与管控：Monitor(司天), Alerts, Overview, Studio(悬镜)
`

---

## 2. 核心交付矩阵

### ① 知识生命周期（知命 · Knowledge Lifecycle）
- 状态机：Active → Weakened → Superseded → Retired
- 实体支持：MemoryItem.lifecycle_status（正交于 status 管道状态）
- 属性拓展：superseded_by, weakened_at, superseded_at, etired_at
- 管理器：KnowledgeLifecycleManager（支持批量扫描自动削弱与退役，防记忆库无限膨胀）

### ② 可解释冲突裁决追踪（直断 · Decision Trace）
- 核心克制原则：**坚决冻结评分维度堆叠**，把 6 维打分转化为可阅读的结构化证据解释
- 结构体：DecisionTrace（包含胜出方、分项分差、最大优势维度说明、自然语言裁决建议）

### ③ 认知自适应中间件（润物 · Cognitive Middleware）
- 被动到主动：打破 Agent 必须主动调用 MCP 心斋的范式
- 接入点：
  - MCP 工具层：handle_search 自动响应 cognitive_summary
  - HTTP 接口层：/cognitive/summary 端点轻量聚合（规则 + 历史教训）
  - ASGI 中间件：CognitiveMiddleware 透传 X-Cognitive-Context

### ④ Behavioral Learning Benchmark (BLB)
量化验证 Agent 因过去经验改变未来行为的 4 项核心指标：
- Learning Rate：避免历史错误的成功比例
- Error Recurrence Rate：同类错误再发率
- Rule Adoption Rate：规则上下文采用率
- Regression Rate：已习得认知的退化率
