## 📌 已规划待开发方向池

### 1. 【探颐】（Tanyi · 记忆主动探针与自然交互消歧）
- **典籍出处**：《易·系辞上》*“探赜索隐，钩深致远”*。
- **核心价值**：改变记忆系统“只被动查询”的现状，让 Agent 在对话中具备主动求证与自然纠错能力。
- **机制要点**：
  - 当检索命中「断金」冲突账本或低置信度模糊事实时，在生成侧 Prompt 中植入轻量追问插桩；
  - Agent 在自然回复末尾顺带询问确认（例如：*“顺便确认下，大哥现在常驻地是转到北京了吗？”*）；
  - 下一轮对话识别用户肯定答复后，自动闭环触发冲突解决（`conflict_resolve`）与版本更替。

---

### 2. 【格物】（Gewu · 因果时序拓扑与事件溯源链）
- **典籍出处**：《礼记·大学》*“致知在格物，物格而后知至”*。
- **核心价值**：突破单点事实记忆，构建具备时序演进与因果逻辑的决策图谱。
- **机制要点**：
  - 扩展 `MemoryEdge` 关系类型：引入 `causes`（导致）、`triggered_by`（触发于）、`leads_to`（导致结果）；
  - 建立事件时间线（Event Timeline），支持复杂因果归因查询（例如：*“兰台为什么在 v0.3.2 决定弃用纯 mock 单测？”* $\rightarrow$ 完整回溯触发事件与决策脉络）。

---

### 3. 【同袍】（Tongpao · 多智能体记忆联邦与公共知识殿堂）
- **典籍出处**：《诗经·秦风·无衣》*“岂曰无衣？与子同袍”*。
- **核心价值**：支持多 Agent 协同体系（Swarm / Agent Teams）下的分级共享与技能互通。
- **机制要点**：
  - 两级存储结构：私有工作区（Agent Private Memory）+ 公共典籍（Swarm Shared Knowledge）；
  - 技能晋升流水线：单个 Agent 验证有效的高频技能结晶（`SkillCrystal`）经考评后发布至公共层，其余 Agent 自动继承共享。

---

### 4. 【悬镜】（Xuanjing · 3D 神经元记忆星图与可视化观测台）
- **典籍出处**：古代神话宝镜，照见万物脉络。
- **核心价值**：提供现代化、极具科技感与直观把控力的 3D WebGL / Force-Directed 记忆宇宙交互看板。
- **机制要点**：
  - 挂载在 `:8767/ui`，实时渲染全库记忆星系（MemoryScene）与实体拓扑连线（MemoryEdge）；
  - 恒星光晕可视化记忆活跃度与艾宾浩斯时效衰减曲线；
  - 支持在 3D 画布上直接拖拽查看证据链、手动合并或归档记忆。
