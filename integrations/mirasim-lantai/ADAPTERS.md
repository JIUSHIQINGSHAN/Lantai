# 三宿主入口规格与验收

依据：本地任务 #1952，集成基线 `7f5e1903`。本模块只生成入口与插件配置，复用既有默认六工具、96 工具完整注册表和宿主帧契约，不新增核心工具、服务 API、前端资源或正式领域名称。

验收接口：`configure.py::build_bundle` 生成宿主原生配置；`configure.py` 命令行默认预览，`--output` 仅写全新审阅目录；`entry.py` 以真实子进程进入现有 MCP 或 Hook。对应测试限定在 `tests/test_adapter_claude_codex_dsh.py`，并单队列复验已有相关契约。

| 切片 | 完成条件 |
| --- | --- |
| 插件发现 | 两份清单引用真实 MCP 文件与技能；去除机器专属桥接路径；默认档固定六工具 |
| Claude Code | 生成 `.mcp.json`；显式 `--hooks` 生成 `.claude/settings.json` |
| Codex | 生成可解析的 `.codex/config.toml`；显式 `--hooks` 同时启用 features.hooks 并生成 hooks.json |
| DSH | 生成归因桥接插件的静态 stdio 配置，默认禁用，保持稳定工具名与逐调用来源标签 |
| 数据与权限 | 缺 API_KEY、相对/非法数据目录在导入服务前拒绝；不保存密钥；来源标签不授予身份 |
| 写出 | 预览零写入；已有输出整项拒绝；写出的文件与预览一致 |
| 协议 | 真实启动、握手、发现、非核心工具拒绝、Hook 注入与回执；坏输入不破坏既有服务契约 |

职责边界：Mirasim 的插件清单负责发现技能/MCP；原生配置供直接使用宿主的场景。两者应择一连接，不能同时注册同名服务。规则文件为接入样本，不承诺 Mirasim 或宿主自动加载。插件启用不启用整段对话采集、核心画像修改或记忆治理。

DSH 使用原有 `integrations/dsh-lantai` 的注册、生命周期、取消、超时与 `_meta` 归因逻辑。本轮只验证合成数据与本机安装的运行时，不读取真实记忆、不安装/启用插件，不证明真实登录态或 GUI 会话成功。

维护者明确授权完整工具集时，另配原生 `lantai-mcp` 并显式设置 `LANTAI_MCP_PROFILE=full`；本包生成的 `entry.py mcp` 固定核心档，不提供隐式扩大暴露面的参数。
