# 兰台长期记忆操作技能 (Lantai Memory Skill)

兰台（Lantai）是本工作台的核心记忆中枢系统，通过 MCP 服务提供标准化记忆与会话知识资产治理能力。

## 常用工具与调用方式

| 工具名 | 用途 | 适用场景 |
| :--- | :--- | :--- |
| `search` | 检索历史记忆条目 | 用户偏好、历史排错、环境配置、长周期事项召回 |
| `add` | 归档新记忆（含分层与标签） | 排错方案沉淀、用户核心里程碑、明确指示记住的事项 |
| `raw_add` | 原始事实直接录入 | 未经蒸馏的一手事实快速入库 |
| `feedback` | 反馈记忆有效性 | 标记某条记忆是否帮到了当前任务，促进记忆演化与遗忘平衡 |
| `add_dialogue` / `dialogue_add_async` | 对话写通道 | 将会话关键对话轮次归档进兰台记忆提取管道 |
| `candidates_pending` | 查询待审候选记忆 | 查看记忆提取工人在后台提纯但置信度低于自动入库门限的条目 |
| `candidate_review` | 裁决候选记忆 | 批准（accept）或驳回（reject）待审候选 |
| `conflicts_list` | 查询事实冲突列表 | 检测记忆库中关于同一主题的矛盾声明 |
| `conflict_resolve` | 裁决事实冲突 | 以新证据或用户裁决解决知识冲突 |
| `get_core_memory` / `put_core_memory` | 用户核心画像槽位 | 查看或更新核心身份与不可变画像 |

## 协同原则
1. **主动召回，自然融入**：查询无需向用户汇报，直接用于支撑准确行动与决策。
2. **提纯沉淀，宁缺毋滥**：只沉淀有复用价值的硬核知识，禁止将临时指令和失败尝试归档。
3. **保持事实权威**：涉及用户个人画像、考研、设备与网络配置，以兰台一手事实记录为准。
